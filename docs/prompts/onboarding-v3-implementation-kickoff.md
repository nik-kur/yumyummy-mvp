1. **Ветка.** В рабочей копии много незакоммиченного: отложенные правки 1.0.11 в `mobile/src/app/paywall.tsx`, неотслеживаемые `docs/knowledge` и `CLAUDE.md`. Создай ветку от main и закоммить туда спецификацию и отложенные правки отдельными коммитами. Коммитить в эту ветку можно без спроса; push, PR и merge в main — после моего ок. Работай в основной папке репозитория, без worktree: сборке iOS нужны уже установленные `node_modules` и поды.
2. **Этапы** (порядок можно уточнить в плане):
   1. Пульт: чтение remote config `onb_main` / `onb_content` / `pw_main` / `pw_after_cancel`, дефолты в коде, экран 0 — анимированная заставка, пока грузится конфиг (до 3 с, раздел «Экран 0» спецификации), арм сохраняется до конца онбординга, `variation_id` в PostHog, слоты Adapty, `logShowFlow`, продукты через `getPaywallProducts`. Плюс QA-переключатель конфига только для dev-сборки, чтобы прогонять любой арм в симуляторе, не трогая Adapty.
   2. Онбординг 1–16 со всеми вариантами, хаптикой, каруселью отзывов, ATT поверх лоадера (AppsFlyer ждёт 180 с), окном оценки.
